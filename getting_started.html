After installing the plugin, open the MavenUp tool window from the IDE's tool-window bar. It is available for Maven projects and gives you a clear overview of the dependencies, plugins, and parent entries used by your project.

First-time workflow

  1. Open the tool window: The table loads your project data from the active Maven modules and shows dependencies, plugins, and parent POM entries. You can also view entries from dependencyManagement and pluginManagement, and the parent section is listed as a dependency with type parent.
  2. Refresh if needed: Use Refresh to reload the current project state and clear any previously selected update values. This is useful after editing a pom.xml or after a Maven import.
  3. Check for newer versions: Click Find New Versions to query Maven repositories and compare the current version of each item with the newest available version. A green checkmark means the item already matches the latest known version; an arrow-up flag shows that a newer release is available.
  4. Choose the version to apply: In the New Version column, select the version you want to use. When multiple entries share the same Maven property such as ${spring.version}, MavenUp keeps the selection in sync automatically. The dropdown text is bold when a pending change is selected, and the tooltip explains the current status.
  5. Update your project: Click Update to review the planned changes in a confirmation dialog and apply the selected versions to the relevant pom.xml files. The Sync Maven Changes after update checkbox is enabled by default and triggers the IDE's Maven sync immediately after the change.

Navigate and inspect entries

  • Jump to the source: Double-click a row (or single-click if configured) to open the matching dependency or plugin entry directly in the editor.
  • Use the context menu: Right-click any row to access Navigate to pom.xml, Open in Maven Repository, and Show Vulnerability Details when findings are available.
  • Open the current artifact page: Select a row and use the top action toolbar to open the current version in the configured repository browser, such as MVN Repository or Sonatype Central.

Check for security issues

  1. Run a vulnerability scan: Click Scan for Vulnerabilities to check the direct dependencies and, when enabled, their resolved transitive dependencies. Results are shown in the Vulnerabilities (Current) column.
  2. Inspect the findings: Select a dependency with findings and click Vulnerability Details or click the populated vulnerability cell. The dialog shows advisory IDs, summaries, severity information, sources, and references for the direct dependency and related transitive findings.

Adjust the plugin to your workflow

Open Settings > Tools > MavenUp to personalize the plugin. You can choose the repository browser, enable single-click navigation, automatically select the newest version, filter out unstable releases, and configure an optional Sonatype OSS Index API token. These options are meant to make first-time use fast and keep the tool window practical for everyday dependency maintenance.
