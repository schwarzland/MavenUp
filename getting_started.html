The plugin opens a tool window named MavenUp (usually located at the right or bottom edge of the IDE). It lists all dependencies and plugins from your pom.xml files, including dependencyManagement and pluginManagement sections.

Basic workflow

  1. Refresh: Reloads the project data and populates the table. Resets any previously selected new versions.
  2. Check for Updates: Searches Maven repositories for available newer versions for all listed entries.
  3. New Version: After the update check, select the desired target version from the dropdown in this column. If multiple entries share the same Maven property (e.g. ${spring.version}), the selection is synchronized automatically.
  4. Update: Shows a confirmation dialog with a summary of all planned changes, then applies the selected version changes to the corresponding pom.xml files.

Vulnerability check

  1. Check Vulnerabilities: Scans direct components and, optionally, resolved transitive dependencies via OSV.dev (and optionally Sonatype OSS Index). Results appear in the Vulnerabilities (Current) column directly after Current Version, showing the total finding count, transitive finding count, and highest severity.
  2. Vulnerability Details: Click a populated cell in the Vulnerabilities (Current) column to open the details dialog. It lists direct and related transitive findings with advisory IDs, CVSS scores, summaries, sources, and clickable references. The actions Open in ... and References... are disabled until you select a finding row, then they apply to that selected advisory. Right-clicking the selected row in any column except References also offers Open in Maven Repository and References....

Navigation & context menu

  • Navigate to pom.xml: Double-click a row (or single-click, if configured) to jump directly to the matching entry in the editor.
  • Right-click context menu: Right-click any row to access Navigate to pom.xml, Open in Maven Repository (opens the current version page in the configured repository browser), and optionally Show Vulnerability Details (opens the vulnerability findings dialog if vulnerabilities are present).

Settings

Configure the plugin under Settings > Tools > MavenUp: choose the repository browser, enable single-click navigation, auto-select the newest version, filter out unstable versions (e.g. RC/beta), and set up optional Sonatype OSS Index credentials.
